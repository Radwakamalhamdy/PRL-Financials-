# Prototyping Lab Financials

Financial tracking and management dashboard for the Prototyping Lab at MSA University.

## 🚀 Features

- **Google Sheets / Spreadsheet Aesthetic**: Authentic cell gridlines, row number indicators, column letter tags (`A` to `F`), and live formula calculation bar (`ƒx`).
- **Dedicated Account**:
  - 🏗️ **Prototyping Lab Financials** (with official RDI watermark)
- **Financial Controls & Receipts**:
  - Track Item, Price (EGP), and InstaPay transaction receipt images.
  - Image preview lightbox with full zoom.
  - Live expenditure tracking and transaction classification (Settled vs Pending).
- **Executive Audit & Reporting**:
  - Settlement breakdown (Settled vs Pending) with status pills.
  - Export to **CSV**, **Excel (.xls)**, **Word (.doc)**, and clean printable **PDF**.
- **Secure Access & Authentication**:
  - Restrict access behind a modern blurred login gateway.
  - Default credentials: `admin` / `prl2026`.
  - Session preservation ("Remember my session") and quick-logout button directly in the header.
- **Offline & Local-First**: Runs directly in the browser with `localStorage` persistence, with real-time multi-device cloud synchronization.

## 🛠️ Built With

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla ES6+)
- LocalStorage API
